# Stretch

9:16 TikTok image stretcher: stretch left/right, blur, blurred backdrop, pinch/drag, export PNG.

## Run on localhost (PC)
Double-click `start.bat`, which opens http://localhost:8080 (needs Python).

## Get the APK (phone)
1. Create a new GitHub repo and upload everything in this folder (including the hidden `.github` folder).
2. Open the repo's **Actions** tab. "Build APK" runs automatically and takes about 5 min.
3. Open the finished run, then download **Stretch-apk** from the Artifacts section. It's a zip containing `app-debug.apk`.
4. Send the APK to your phone, open it, and allow "Install unknown apps" when asked.

In the app, **Save image** opens the share sheet, so you can save to Photos/Gallery or send it straight to TikTok.
